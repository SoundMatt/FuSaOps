# IEC 61508 — Functional safety of E/E/PE systems

FuSaOps supports IEC 61508 by aggregating the SIL-oriented evidence each
language tool produces.

## How FuSaOps contributes

| IEC 61508 area | FuSaOps contribution |
|---|---|
| Part 3 §7.4 (software design & development) | Aggregates coding-standard and static-analysis findings across languages |
| Part 3 Annex A/B (techniques) | Each tool maps its checks to the relevant techniques; FuSaOps gates on the union |
| Part 1 §7.18 (functional safety assessment) | Aggregated report + committed evidence bundle for the assessor |
| Part 3 §6 (configuration mgmt) | Tagged releases, SBOM/provenance, hashed artefact manifest |

## SIL handling

Per-language SIL gap assessment is produced by each tool (e.g. `gofusa iec61508`,
`cpfusa iec61508`). FuSaOps runs them and presents one aggregate verdict;
a skipped component is an explicit gap in the assessment.
