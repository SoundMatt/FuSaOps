# ISO/SAE 21434 — Road vehicles, cybersecurity engineering

FuSaOps aggregates the cybersecurity evidence each language tool produces
(CWE-mapped findings, TARA, threat scenarios).

## How FuSaOps contributes

| ISO 21434 area | FuSaOps contribution |
|---|---|
| Clause 8 (continuous cybersecurity) | Aggregates each tool's CWE-mapped `cyber` findings into one gate |
| Clause 9 (concept / TARA) | Each tool generates a TARA; FuSaOps presents the aggregate picture |
| Clause 15 (incident response) | `INCIDENT-RESPONSE.md` for the tool itself |
| Supply chain | SBOM + provenance for the FuSaOps release and bundled tools |

## Notes

Per-language threat analysis and cyber rules belong to each tool
(e.g. `gofusa cyber`, `gofusa tara`). FuSaOps normalises and merges their
findings, preserving CWE/severity and language attribution.
